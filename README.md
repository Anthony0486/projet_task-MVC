# Task MVC

Application web de gestion de tâches développée en PHP suivant une architecture MVC.

## Aperçu

Task MVC est une application permettant aux utilisateurs de gérer leurs tâches quotidiennes via une interface simple et fonctionnelle.

Le projet met en pratique les fondamentaux du développement full-stack avec :
- gestion des utilisateurs,
- authentification,
- interactions base de données,
- architecture MVC,
- gestion de sessions.

## Fonctionnalités

### Authentification
- Création de compte utilisateur
- Connexion utilisateur
- Déconnexion sécurisée
- Modification du mot de passe

### Gestion des tâches
- Ajouter une tâche
- Modifier une tâche
- Supprimer une tâche
- Marquer une tâche comme terminée

## Stack technique

### Front-end
- HTML5
- CSS3
- JavaScript

### Back-end
- PHP

### Base de données
- MySQL

## Architecture

Le projet suit une architecture MVC :
- Models : gestion des données et interactions SQL
- Views : affichage des pages
- Controllers : logique applicative et traitement des requêtes

## Objectifs du projet

Ce projet a été réalisé dans le cadre de ma formation afin de :
- pratiquer l’architecture MVC en PHP,
- manipuler une base de données relationnelle,
- gérer l’authentification utilisateur,
- développer une application CRUD complète.
